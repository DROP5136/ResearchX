# @researchx/contracts

Shared TypeScript API contracts used by `apps/web` and optionally `apps/server`.

- `api/` — request/response DTO shapes (User, Project, ResearchSession, …)
- `schemas/` — shared enums/constants (research depth, pipeline stages)

Python Pydantic schemas stay in `apps/ai-service/app/schemas` and `app/api/schemas`.
